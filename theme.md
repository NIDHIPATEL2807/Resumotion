## Theme 1: Context Window (the smart one)

**The concept:** the whole reel is one AI conversation streaming live. Ninosauraus asks the question, an AI agent "thinks", calls tools, and every tool result expands into a scene. The final answer is you.

Perception says "I build computer vision." This theme says "I build agents and understand context engineering", which is exactly your Barclays work, so the theme itself proves the skill.

**Look**
- Light theme, to contrast with Perception's black.
  - Background `#EEF1F4` (cool porcelain).
  - Ink `#0E1116`.
  - Your orange `#FF6B2B` used only for *attention*: highlighting the words the model is "looking at".
- Fonts: **Instrument Serif** for the model's answers, which feels human and elegant. **Geist Mono** for tokens, tool calls and JSON.
- Signature visual: **attention lines**. Thin curves connect the question to the words that answer it, like a transformer's attention map, so you can literally see the model "think".

**Sound**
- 92 BPM, soft lo-fi.
- The trick: **every streamed token is a tiny click, and the stream itself becomes the hi-hat.** When text streams fast the rhythm speeds up; when the model "thinks", it goes quiet. The text and the beat are the same thing.
- Tool calls land on the downbeat with a soft *thunk*. The final answer gets a warm chord.

- **Name:** the model streams "Nidhi Patel" token by token. Attention lines shoot from the question to the name. A context bar fills: `context: 2,048 / 200k tokens`.

  2. Then `build_pipeline()` streams its stages one by one.
  3. Then the clever bit: the context bar **saves a block, clears, and resumes mid-pipeline**. That's your real "portable context blocks" idea, shown literally.
- **Volkswagen, FortiPhrase:** `run_project("...")` returns a card with a mini live visual: a tiny road with hazard boxes, a password decoding.

- **Wins:** `search("hackathons")` returns 5 ranked results with relevance scores, each with its logo.
- **Skills:** `list_tools()` returns your skills as a JSON tool manifest. Each category is a tool, each skill a parameter.
